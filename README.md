# Randomizer

Randomizer — веб-приложение для проведения случайных выборов и розыгрышей с современным интерфейсом, анимациями, подсветкой и звуковыми эффектами.

В первой версии планируются два режима: выбор победителя из списка участников и генерация случайного числа в заданном диапазоне. Зарегистрированные пользователи смогут сохранять свои рандомайзеры и просматривать историю запусков.

## Структура проекта

- `website/client` — клиентское приложение на Vue.js и TypeScript;
- `website/server` — API на NestJS, Prisma и PostgreSQL;
- `landing` — публичная презентационная страница проекта;
- `MVP.md` — требования, архитектурные решения и план разработки первой версии.

Проект находится на начальном этапе. Инструкции по установке, запуску и разработке будут добавляться по мере подготовки приложений.
