# Randomizer Client

Клиентская часть Randomizer отвечает за пользовательский интерфейс, создание и запуск рандомайзеров, отображение истории результатов, анимации и звуковые эффекты.

Планируемый стек:

- Vue 3;
- TypeScript;
- Vite;
- Pinia;
- Vue Router;
- TanStack Query.

Интерфейс будет адаптивным, доступным с клавиатуры и учитывать системную настройку уменьшения анимаций. Инструкции по установке и запуску появятся после инициализации клиентского приложения.
