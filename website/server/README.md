# Randomizer Server

Серверная часть Randomizer предоставляет API для авторизации, управления сохранёнными рандомайзерами, выполнения случайного выбора и хранения истории результатов.

Планируемый стек:

- NestJS;
- TypeScript;
- Prisma ORM;
- PostgreSQL;
- JWT и Argon2;
- Swagger/OpenAPI;
- структурированное логирование через Pino.

В production будут записываться только полезные события: запуск сервера, регистрация и авторизация, важные действия пользователя, предупреждения и ошибки. Секреты, пароли, токены и лишние технические операции логироваться не будут.

Инструкции по настройке окружения, миграциям и запуску появятся после инициализации серверного приложения.
